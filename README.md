# EasePal Care — Private Partnership ROI & Scaling Model

## Purpose

This project documents and models the cost of scaling the EasePal Care community-based healthcare delivery model from an initial CHEW deployment to large-scale implementation.

The model focuses on two primary questions:

1. What does it cost to recruit, train, equip, deploy, and sustain CHEWs at different scales?
2. How much recurring revenue can be generated from patient subscriptions at different subscription prices?

## Core Operating Model

The Oyo State Executive Summary establishes a 1 CHEW : 10 patients service model.

This project uses that ratio as the primary scaling assumption.

## Scope

The first version is intentionally simple.

It will model:

- CHEW deployment costs
- Training costs
- Equipment and setup costs
- Recurring CHEW service-delivery costs
- Logistics
- Shared/overhead costs
- Patient subscription revenue
- Scaling from 10 to 5,000 CHEWs

## Design Principle

The reasoning, assumptions, formulas, and decisions used to create the model will be documented before the calculator is built.
