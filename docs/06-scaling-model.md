# Scaling Model

## Core Formula

Patients = CHEWs × 10

## Planned Scenarios

| CHEWs | Patients |
|---:|---:|
| 10 | 100 |
| 50 | 500 |
| 100 | 1,000 |
| 200 | 2,000 |
| 500 | 5,000 |
| 1,000 | 10,000 |
| 2,000 | 20,000 |
| 5,000 | 50,000 |

## Cost Scaling

The model will calculate costs according to their cost driver:

### Per CHEW

Cost = Number of CHEWs × Cost per CHEW

### Per Patient

Cost = Number of Patients × Cost per Patient

### Per Location

Cost = Number of Locations × Cost per Location

### Fixed / Shared

Cost = Defined fixed amount

### Percentage-Based

Cost = Defined percentage × relevant base

## Objective

The model should allow management to compare the cost and subscription revenue implications of each scaling level.
