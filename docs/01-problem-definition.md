# Problem Definition

## 1. Background

EasePal Care is developing a community-based healthcare delivery model using Community Health Extension Workers (CHEWs), supported by a digital platform.

The Oyo State Executive Summary establishes a service model of:

**1 CHEW : 10 patients**

The purpose of this project is to create a simple, transparent financial model that can determine the cost and revenue implications of scaling this model.

## 2. Problem We Are Solving

Before scaling the programme, we need to understand:

- What does it cost to prepare one CHEW for deployment?
- What does it cost to deploy one CHEW?
- What does it cost to maintain one CHEW?
- What costs increase with patient volume?
- What costs remain fixed as the programme scales?
- How much revenue can subscriptions generate per patient?
- At what scale does the model become financially sustainable?

## 3. Primary Questions

### Cost Question

What is the total cost of scaling from:

10 → 50 → 100 → 200 → 500 → 1,000 → 2,000 → 5,000 CHEWs?

### Revenue Question

If each CHEW serves 10 patients, how much subscription revenue is generated at different subscription prices?

## 4. Scope Boundary

This first model is NOT a full healthcare operations dashboard.

It is a financial scaling calculator focused on:

- Costing
- Scaling
- Subscription revenue
- Basic contribution analysis

## 5. Documentation Principle

No cost should be introduced without identifying:

1. The activity that creates the cost.
2. The cost item associated with that activity.
3. The cost driver.
4. Whether the cost is fixed or variable.
5. The assumption or source supporting the amount.

Where a value is not yet known, it will be marked **TBD** rather than invented.

## 6. Success Criteria

The model should allow a user to change the number of CHEWs and subscription price and immediately see the resulting:

- Number of patients
- Setup cost
- Recurring cost
- Monthly subscription revenue
- Annual subscription revenue
- Contribution

## 7. Source

The initial operating assumptions are based on the EasePal Care Oyo State Executive Summary.
